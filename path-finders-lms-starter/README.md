# Path Finders LMS

A modern starter Learning Management System for Sri Lankan Commerce A/L students.

## Stack
- HTML, CSS and vanilla JavaScript
- Supabase Auth + PostgreSQL + Row Level Security
- Chart.js for progress visualisation
- Any static host such as Vercel, Cloudflare Pages or GitHub Pages

## Project status
This package is a clean starter implementation based on the supplied requirements. Replace placeholder contact/branding content and connect your Supabase project before production use.

See `docs/SETUP.md` for setup instructions.
